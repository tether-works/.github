# >_ tetherworks.dev

**Independent software workbench — zero telemetry, no ads, no trackers.**

Everything published here is built to load fast, run locally without telemetry or tracking scripts, and stay out of your way.

### Shipped Projects

- **[IgnisDisc](https://ignisdisc.tetherworks.dev)** ([tether-works/IgnisDisc](https://github.com/tether-works/IgnisDisc)) — free, open-source CD and DVD burner and audio CD ripper for Windows 10 and 11: data, audio and image burning, AccurateRip checks, and multi-disc archives with PAR2 recovery data. Tested against a built-in virtual drive and on real CD-R, CD-RW, DVD-R and DVD+RW discs.
- **[KiloOS: A Return to 1999 (v0.4.38)](https://kilo.tetherworks.dev)** — Browser-based 1999 desktop environment housing a fleet of **104 minimalist, instant-loading applications and 60fps games** (KChrono, KStarForge, KRogue, KCosmic, KTerm, KBBS, KNet).
