### How I Direct Agents (Anti-Vibe-Coding Protocol)

- **Never Trust "Done" Without Automated Proof:** Agents cannot declare a task finished until the compiler exits with zero warnings and an automated test, simulator, or vision check proves the user-visible outcome.
- **Build the Simulator First:** Before agents touch UI or hardware workflows, they build an in-memory simulator or headless vision-model playtest loop so they can catch and fix their own mistakes unattended.
